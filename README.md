# 🌊 全国波情報

全国36の主要サーフスポット(北海道〜沖縄・日本海側含む)の波情報を1ページにまとめたものです。
ブラウザで開くたびに [Open-Meteo](https://open-meteo.com/) の海洋気象API(無料・キー不要)から最新の予報を取得します。
サーバー不要の単一 HTML ファイル(`index.html`)で動作します。

## 公開先

https://anji-1173.github.io/nami-info/

スマホのブラウザで開いて「ホーム画面に追加」すると、アプリのように使えます。

## 機能

- **地図検索 → 詳細画面** — 日本地図（埋め込みSVG・外部地図サービス不要）に全スポットをプロット。ラベルは自動配置(密集地は引き出し線)。地図やカードをタップするとそのポイントの**詳細画面**へ遷移(URLハッシュ管理・ブラウザの戻る対応)
- **週間コンディション** — 8日先まで各日を風・波浪予報から◎○△▽×で評価。詳細画面の週間表(行タップで日付切替)と、一覧カードの週間バー上の記号で確認できる
- **台風うねりアラート** — 波浪モデルは台風を含む風予報で駆動されるため台風うねりも反映される。うねりが急上昇する日(前日比+0.6m以上かつ1m以上、または周期12秒以上)には **⚠急上昇** を表示し、気象庁の台風情報へリンク
- **サイズ着色(アタマ基準)** — 地図の●とカードのバッジは、フラット=グレー、〜カタまで=青の濃淡、**アタマ級=アンバー(上級者)、ダブル級〜=赤(プロ級)** と、アタマを境に警戒色へ切り替わる配色
- **コンディション評価** — **◎最高 ○良い △普通 ▽イマイチ ×ダメ** の5段階。サイズ・風向(オフ/サイド/オンショア)・風速・うねりの周期から判定し、モモ〜コシ以下は▽止まり、スネ以下やクローズ級は×
- **サイズ（ブレイク推定）** — うねりの向きとビーチの向きの一致度・周期から**実際に立つ波の目安**を推定して表示（届かない向きのうねりや短周期の風波は割引。スポット別の補正係数 `cal` でも調整可能）。沖合有義波高と**うねりの高さ(m)**も併記、週間バーつき
- **波数** — うねりの周期と風波の割合から「少なめ / 普通 / 多め」を推定
- **うねりの向き・周期** — 方位と矢印、平均周期(秒)
- **満潮・干潮時間** — 潮位モデルから抽出。展開すると1日の潮位カーブを表示
- **風** — 午前/午後の風向・風速と、ビーチの向きから判定したオフ/オンショア
- 地域(関東・日本海など)と日付(今週7日分)で絞り込み。ライト/ダーク対応、スマホ対応
- データは1時間 localStorage にキャッシュ。`?demo=1` を付けるとオフラインのデモデータで表示

※ 沖合の有義波高にもとづく目安です。実際のブレイクサイズはポイントの地形で変わります。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体(画面・計算・API取得がすべてこの1ファイル) |
| `sw.js` | オフライン対応と更新検知(Service Worker) |
| `manifest.webmanifest` | ホーム画面に追加したときのアプリ名・色の設定 |
| `icon-180.png` / `icon-192.png` / `icon-512.png` | アイコン |

## ローカルで使う

`index.html` をブラウザで開くだけで動きます(オフライン対応は `https://` でのみ有効)。

## 公開の設定をやり直すとき

**Settings → Pages** を開き、**Source** を「Deploy from a branch」、**Branch** を `main` と `/ (root)` にして **Save**。反映まで数分かかります。
